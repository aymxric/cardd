Limites et continuité ▼

La limite d'une fonction décrit son comportement quand x tend vers une valeur ou l'infini.

  • Limite infinie : lim f(x) = +∞ quand x → a si f(x) devient arbitrairement grand
  • Formes indéterminées : ∞−∞, 0/0, ∞/∞, 0×∞ → lever l'indétermination
  • Croissances comparées : eˣ domine xⁿ qui domine ln(x) en +∞
  • Théorème des gendarmes : g ≤ f ≤ h et g→L et h→L ⟹ f→L
  • Continuité en a : f définie en a, limite en a = f(a)
  • Théorème des valeurs intermédiaires (TVI) : si f continue sur [a,b], pour tout k entre f(a) et f(b), il existe c tel que f(c) = k
Règle de l'Hôpital (f/g → 0/0 ou ∞/∞) : lim f/g = lim f'/g'
Dérivation — formules et applications ▼
  • (xⁿ)' = nxⁿ⁻¹ | (eˣ)' = eˣ | (ln x)' = 1/x
  • (sin x)' = cos x | (cos x)' = −sin x
  • (uv)' = u'v + uv' | (u/v)' = (u'v − uv')/v²
  • (f∘g)'(x) = g'(x)·f'(g(x))
(e^u)' = u'·e^u | (ln u)' = u'/u | (uⁿ)' = n·u'·uⁿ⁻¹

Applications : étude de variations (signe de f'), équation de tangente y = f(a) + f'(a)(x−a), extrema locaux.

Dérivée seconde : f''(x) = (f'(x))'. Si f'' > 0 → f convexe ; f'' < 0 → f concave. Point d'inflexion : f'' change de signe.

Intégration ▼
∫ₐᵇ f(x) dx = [F(x)]ₐᵇ = F(b) − F(a)
  • ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C | ∫ eˣ dx = eˣ + C | ∫ 1/x dx = ln|x| + C
  • ∫ cos x dx = sin x + C | ∫ sin x dx = −cos x + C
  • ∫ u'/u dx = ln|u| + C | ∫ u'·eᵘ dx = eᵘ + C
Intégration par parties : ∫ u·v' = [uv] − ∫ u'·v
Changement de variable : ∫ f(g(x))g'(x)dx = ∫ f(u) du (u = g(x))

Valeur moyenne : <f> = (1/(b−a))·∫ₐᵇ f(x)dx

Aire entre deux courbes : A = ∫ₐᵇ |f(x) − g(x)| dx

Équations différentielles ▼
y' = ay → y = Ke^(at) (K déterminé par CI)
y' = ay + b → y = Ke^(at) − b/a

Équation du second ordre : y'' + ω₀²·y = 0 → y = A cos(ω₀t) + B sin(ω₀t)

  • Identifier le type, trouver une solution particulière, puis la solution homogène
  • Condition initiale : valeur en t=0 pour déterminer K
  • Modélisation : croissance/décroissance exponentielle, circuit RC, oscillateur
Suites numériques ▼
Arithmétique : uₙ = u₀ + n·r | Sₙ = (n+1)(u₀+uₙ)/2
Géométrique : uₙ = u₀·qⁿ | Sₙ = u₀·(1−qⁿ⁺¹)/(1−q) (q≠1)
  • Suite récurrente linéaire : uₙ₊₁ = a·uₙ + b → chercher le point fixe l = al+b
  • vₙ = uₙ − l est géométrique de raison a
  • Convergence : si |q| < 1, uₙ→0. Si q≥1, diverge
  • Raisonnement par récurrence : initialisation → hérédité
  • Suite monotone bornée → convergente (admis)
Probabilités — loi binomiale & loi normale ▼
Loi binomiale B(n,p) : P(X=k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ
E(X) = np | σ(X) = √(np(1−p))
Loi normale N(μ,σ²) : P(μ−σ < X < μ+σ) ≈ 68% | ±2σ ≈ 95%
Intervalle de confiance 95% : p̂ ± 1,96√(p̂(1−p̂)/n)
  • Loi normale centrée réduite N(0,1) : Z = (X−μ)/σ
  • Test d'hypothèse : H₀ (hypothèse nulle), p-valeur, région de rejet au seuil α
  • Variable aléatoire continue : densité f(x) avec ∫ f(x)dx = 1
  • Loi des grands nombres : fréquence → probabilité quand n → ∞
Géométrie dans l'espace — vecteurs & plans ▼
Produit scalaire : u⃗·v⃗ = x₁x₂ + y₁y₂ + z₁z₂ = |u⃗||v⃗|cos θ
Équation de plan : ax + by + cz + d = 0 (vecteur normal n⃗(a,b,c))
Distance point-plan : d = |ax₀+by₀+cz₀+d| / √(a²+b²+c²)
  • Droite paramétrique : M = A + t·v⃗ (t∈ℝ)
  • Colinéarité : u⃗ ∥ v⃗ ⟺ u⃗ = λv⃗
  • Orthogonalité : u⃗ ⊥ v⃗ ⟺ u⃗·v⃗ = 0
  • Sphère de centre Ω(a,b,c) et rayon r : (x−a)²+(y−b)²+(z−c)² = r²
Nombres complexes ▼
z = a + ib | |z|² = a² + b² | z̄ = a − ib
Forme trigonométrique : z = r(cos θ + i sin θ) = r·e^(iθ)
Formule d'Euler : e^(iθ) = cos θ + i sin θ
  • Multiplication : |z₁z₂| = |z₁||z₂| et arg(z₁z₂) = arg(z₁) + arg(z₂)
  • Formule de Moivre : (e^(iθ))ⁿ = e^(inθ)
  • Racines nièmes de l'unité : zₖ = e^(2ikπ/n) pour k=0,...,n−1
  • Interprétation géométrique : multiplication par e^(iθ) = rotation d'angle θ
Algèbre linéaire — matrices & systèmes ▼
  • Opérations sur matrices : addition, produit (lignes × colonnes), transposée
  • Matrice inverse A⁻¹ : AA⁻¹ = I | det(A) ≠ 0
  • Résolution AX = B : X = A⁻¹B (si A inversible)
det([[a,b],[c,d]]) = ad − bc

Pivot de Gauss : substitution successive pour résoudre les systèmes.

Graphes et matrices : matrice d'adjacence, suites définies par récurrence vectorielle uₙ₊₁ = M·uₙ.

Étude complète d'une fonction ▼
  • 1. Domaine Df : annuler dénominateurs, ln>0, √≥0
  • 2. Parité/périodicité : f(−x) vs f(x)
  • 3. Limites aux bornes et en ±∞ + asymptotes
  • 4. Dérivée f'(x), tableau de signe, extrema
  • 5. Convexité f''(x), points d'inflexion
  • 6. Tableau de variations complet
  • 7. Courbe avec points caractéristiques et asymptotes
Récurrence — structure d'une preuve ▼
  • Initialisation : vérifier la propriété P(n₀)
  • Hérédité : supposer P(n) vraie (HR), montrer P(n+1)
  • Conclusion : par le principe de récurrence, P(n) vraie pour tout n ≥ n₀
Calculer une probabilité conditionnelle ▼

Formule des probabilités totales : P(A) = Σ P(A|Bᵢ)·P(Bᵢ)
Bayes : P(Bᵢ|A) = P(A|Bᵢ)·P(Bᵢ) / P(A)

Géométrie analytique — trouver une intersection ▼
  • Droite ∩ Plan : substituer les paramètres de la droite dans l'équation du plan
  • Plan ∩ Plan : résoudre le système de deux équations (droite d'intersection)
  • Vérifier que les résultats sont bien dans les deux ensembles

Mécanique — lois de Newton ▼
2e loi de Newton : Σf⃗ = m·a⃗ (dans un référentiel galiléen)
  • 1ère loi (inertie) : si Σf⃗ = 0⃗ → vitesse constante (ou nulle)
  • 3ème loi (réciprocité) : f⃗(A→B) = −f⃗(B→A)
  • Poids : P⃗ = m·g⃗ (g ≈ 9,81 m/s² sur Terre)
  • Force de frottement fluide : f⃗ = −k·v⃗
  • Référentiels : terrestre (galiléen approx.), géocentrique, héliocentrique
Projectile : x = v₀cosα·t | y = v₀sinα·t − ½gt²
Vitesse : vx = v₀cosα (cste) | vy = v₀sinα − g·t
Énergie mécanique et travail ▼
Ec = ½mv² | Ep = mgh | Em = Ec + Ep
Travail : W = F·d·cos θ (J) | Puissance : P = W/t = F·v·cos θ (W)
  • Théorème travail-énergie cinétique : ΔEc = ΣW(toutes les forces)
  • Conservation de Em si seul le poids travaille (forces conservatives)
  • Énergie potentielle élastique : Ep = ½kx²
  • Rendement : η = P_utile / P_totale
Oscillations — pendule et ressort ▼
Équation du mouvement : ẍ + ω₀²x = 0 → x(t) = A cos(ω₀t + φ)
Ressort : ω₀ = √(k/m) | T₀ = 2π√(m/k)
Pendule simple : ω₀ = √(g/l) | T₀ = 2π√(l/g)
  • Oscillateur amorti : ẍ + 2λẋ + ω₀²x = 0 (λ = facteur d'amortissement)
  • Résonance en amplitude : ω_r = √(ω₀² − 2λ²)
  • Régime critique (λ = ω₀) : retour à l'équilibre le plus rapide sans oscillation
  • A et φ déterminés par les conditions initiales x(0) et ẋ(0)
Électricité — circuits et dipôles ▼
Ohm : U = RI | P = UI = RI² = U²/R
Condensateur : i = C·du/dt | u_C(t) = E(1 − e^(−t/τ)) en charge
Bobine : u = L·di/dt | RC : τ = RC | RL : τ = L/R
RLC série : ω₀ = 1/√(LC) | Q = Lω₀/R = 1/(RC·ω₀)
  • Lois de Kirchhoff : ΣI = 0 (nœuds) | ΣU = 0 (mailles)
  • Valeur efficace : U_eff = U_max/√2 | P = U_eff·I_eff·cosφ
  • Impédances : Z_R = R | Z_C = 1/(Cω) | Z_L = Lω
  • Résonance série : Z_min = R à ω₀ → I_max
Optique — ondes et lumière ▼
Snell-Descartes : n₁ sin i₁ = n₂ sin i₂
v = λf | T = 1/f | c = 3×10⁸ m/s | n = c/v
  • Réflexion totale : sin i_c = n₂/n₁ (avec n₁ > n₂)
  • Diffraction : centrale plus grande que λ/a est grand (a = taille obstacle)
  • Interférences Young : δ = a·x/D | frange brillante si δ = kλ
  • Lentille convergente : 1/v − 1/u = 1/f' | γ = v/u | f' = 1/D (dioptries)
  • Effet Doppler : f_obs = f_source × (c + v_obs)/(c − v_source) (approche)
Thermodynamique ▼
Gaz parfait : PV = nRT (R = 8,314 J/mol·K | T en Kelvin)
1er principe : ΔU = W + Q
  • Transformations : isotherme T=cste | isobare P=cste | isochore V=cste | adiabatique Q=0
  • Énergie interne gaz parfait monoatomique : U = (3/2)nRT → ΔU = nCvΔT
  • Transfert thermique par conduction : φ = λS(T₂−T₁)/e
  • Machine thermique : rendement η = W/Q_chaud ≤ 1 − T_froid/T_chaud (Carnot)
Chimie — équilibres et cinétique ▼
Constante d'équilibre : K = Π[produits]^ν / Π[réactifs]^ν
Acides-bases : pH = −log[H₃O⁺] | pKa = −log Ka | pH = pKe − pOH
Loi de vitesse : v = k[A]^α[B]^β
  • Taux d'avancement : τ = x_éq / x_max
  • Henderson-Hasselbalch : pH = pKa + log([A⁻]/[HA])
  • Cinétique ordre 1 : [A] = [A]₀·e^(−kt) | t½ = ln2/k
  • Cinétique ordre 2 : 1/[A] = 1/[A]₀ + kt
  • Énergie d'activation : k = A·e^(−Ea/RT) (loi d'Arrhenius)
Chimie organique — réactions et mécanismes ▼
  • Substitution nucléophile (SN) : Nu: attaque le C portant le nucléofuge → SN1 ou SN2
  • Élimination (E) : formation d'une double liaison, compétition avec SN
  • Addition électrophile (AE) : sur alcènes — règle de Markovnikov (H+ sur C le plus hydrogéné)
  • Oxydoréduction : alcool primaire → aldéhyde → acide | secondaire → cétone
  • Estérification : acide + alcool ⇌ ester + eau (lente, limitée, athermique)
  • Saponification : ester + HO⁻ → carboxylate + alcool (totale, rapide)
  • Polymérisation : addition (alkène) ou condensation (polyester, polyamide)
Physique quantique et nucléaire ▼
Énergie photon : E = hf = hc/λ (h = 6,626×10⁻³⁴ J·s)
Énergie-masse : E = mc² | Défaut de masse : Δm = Z·mₚ + N·mₙ − m_noyau
Décroissance radioactive : N(t) = N₀·e^(−λt) | t½ = ln2/λ | A = λN
  • Désintégrations : α (−2p−2n), β⁻ (n→p+e⁻+ν̄), β⁺ (p→n+e⁺+ν), γ (énergie seule)
  • Lois de conservation : A (nucléons), Z (charge), énergie-masse
  • Niveaux d'énergie : ΔE = hf pour photon émis ou absorbé
  • Dualité onde-corpuscule : λ_de_Broglie = h/(mv)

Résoudre un problème de mécanique ▼
  • 1. Schéma : système, forces, référentiel galiléen
  • 2. Bilan des forces : poids, réaction normale, frottement, tension...
  • 3. Appliquer Newton : Σf⃗ = ma⃗, projeter sur les axes x et y
  • 4. Résoudre les équations différentielles ou algébriques
  • 5. Conditions initiales : x(0), y(0), vx(0), vy(0)
  • 6. Vérifier les dimensions (homogénéité) et le sens physique
Analyser un circuit électrique ▼
  • Identifier les mailles, les nœuds, les dipôles
  • Appliquer les lois de Kirchhoff (courants aux nœuds, tensions aux mailles)
  • Écrire l'équation différentielle si condensateur ou bobine
  • Résoudre : solution homogène + solution particulière
  • Appliquer la condition initiale (u_C(0) ou i_L(0))
Dosage — calcul de concentration ▼
À l'équivalence : n_acide = n_base (réaction 1:1)
n = C × V (mol = mol/L × L)
  • Point d'équivalence : dérivée max de la courbe pH, ou indicateur coloré
  • Avant l'équivalence : réactif titré en excès
  • Après l'équivalence : réactif titrant en excès

La conscience ▼

Définition : Faculté de l'esprit à se représenter soi-même et le monde. Double sens : conscience psychologique (avoir des perceptions, pensées) et conscience morale (sens du bien et du mal).

  • Conscience immédiate : présence à soi-même dans l'instant (cogito de Descartes)
  • Conscience réflexive : se prendre soi-même pour objet de pensée
  • Problème du rapport âme/corps : dualisme cartésien vs monisme
  • L'inconscient remet-il en cause la toute-puissance de la conscience ? (Freud)
Descartes : « Je pense, donc je suis » — le cogito comme certitude première
Sartre : la conscience est « néant », elle est conscience de quelque chose (intentionnalité)
DescartesHegelSartreFreud
L'inconscient ▼

Définition : Ce qui échappe à la conscience tout en influençant nos pensées, désirs et comportements.

  • Freud : 3 instances — Ça (pulsions), Moi (médiateur), Surmoi (normes intériorisées)
  • Mécanismes de défense : refoulement, déni, projection, sublimation
  • Expressions de l'inconscient : rêves, lapsus, actes manqués, symptômes
  • Objection : l'inconscient supprime-t-il la liberté et la responsabilité ?
Freud : « Le moi n'est pas maître dans sa propre maison »
FreudLacanSartre (contre)
La liberté ▼

Définition : Pouvoir d'agir selon sa propre volonté, sans contrainte extérieure ni intérieure.

  • Libre arbitre (Descartes) : faculté de choisir sans être déterminé
  • Déterminisme (Spinoza, Marx) : tout effet a une cause, l'illusion de liberté vient de l'ignorance des causes
  • Liberté politique : liberté négative (absence de contrainte) vs positive (capacité réelle d'agir)
  • Sartre : « L'existence précède l'essence » — l'homme est condamné à être libre
  • Liberté et responsabilité : être libre implique d'assumer ses choix
Spinoza : « Les hommes se croient libres parce qu'ils ont conscience de leurs désirs mais ignorent les causes qui les déterminent »
DescartesSpinozaRousseauKantSartre
Le désir ▼

Définition : Tendance vers ce dont on manque et qui procurerait satisfaction. Distinct du besoin (naturel) et de la volonté (rationnelle).

  • Platon (Banquet) : le désir comme manque — on désire ce qu'on n'a pas
  • Spinoza : le désir est l'essence même de l'homme (conatus)
  • Épicure : distingue désirs naturels/nécessaires des désirs vains → chercher l'ataraxie
  • Le désir peut-il être satisfait ? Problème de l'insatisfaction perpétuelle (Schopenhauer)
  • Désir mimétique : on désire ce que l'autre désire (Girard)
Épicure : classifier les désirs → naturels et nécessaires (manger) / naturels non nécessaires / vains (gloire)
PlatonÉpicureSpinozaHegelSchopenhauer
La raison et le réel ▼

Raison : Faculté de penser selon des principes logiques et universels. Réel : Ce qui existe indépendamment de notre représentation.

  • Rationalisme (Descartes, Kant) : la raison produit des vérités a priori
  • Empirisme (Hume, Locke) : toute connaissance vient de l'expérience sensible
  • Criticisme kantien : synthèse — l'entendement met de l'ordre dans les données sensibles
  • La science est-elle rationnelle ? Popper : falsifiabilité comme critère
Kant : « Des intuitions sans concepts sont aveugles ; des concepts sans intuitions sont vides »
DescartesHumeKantPopper
La vérité ▼

Définition : Adéquation d'un énoncé avec la réalité (vérité-correspondance), ou cohérence d'un système logique (vérité-cohérence).

  • Vérité vs opinion (doxa) : la vérité est universelle, l'opinion est subjective
  • Vérité scientifique : provisoire, falsifiable, soumise à révision (Popper)
  • Vérité et certitude : peut-on être certain d'une vérité ? (Descartes : doute méthodique)
  • Pragmatisme (James) : une vérité est ce qui est utile, ce qui marche
  • Relativisme : y a-t-il des vérités absolues ou tout est-il relatif à une culture ?
Nietzsche : « Il n'y a pas de faits, seulement des interprétations » — perspectivisme
PlatonDescartesNietzschePopper
Le langage ▼

Définition : Système de signes permettant la communication et l'expression de la pensée.

  • Signe linguistique (Saussure) : signifiant (image acoustique) + signifié (concept) — arbitraire
  • Langage et pensée : le langage structure-t-il la pensée ou l'inverse ? (Wittgenstein)
  • Langage comme pouvoir : rhétorique, mensonge, propagande
  • Langage propre à l'homme ? Parole vs communication animale (Aristote)
  • Performatif (Austin) : certains énoncés font ce qu'ils disent (promettre, jurer)
Wittgenstein : « Les limites de mon langage signifient les limites de mon propre monde »
AristoteSaussureWittgensteinAustin
Le temps ▼

Définition : Dimension de l'existence marquée par la succession passé-présent-futur et par la conscience de la durée.

  • Temps objectif (physique) vs temps subjectif (vécu, durée bergsonienne)
  • Augustin : le passé est dans la mémoire, le présent dans l'attention, le futur dans l'attente
  • Heidegger : l'être-pour-la-mort structure notre rapport au temps (souci, projet)
  • Bergson : la durée réelle (intuition) vs le temps spatialisé (mesuré)
  • Problème : peut-on agir sur le passé ? Sens de l'histoire.
Heidegger : « L'être-pour-la-mort » — l'angoisse face à la finitude nous révèle notre liberté

La société et l'État ▼

Société : Ensemble d'individus liés par des règles, des institutions et des pratiques communes. État : Institution politique souveraine disposant du monopole de la violence légitime.

  • Contrat social : Rousseau (volonté générale), Hobbes (Léviathan contre guerre de tous contre tous), Locke (droits naturels)
  • État de nature : hypothèse pour penser les fondements de la société politique
  • Légitimité du pouvoir : consentement (démocratie), tradition, charisme (Weber)
  • Marx : l'État comme outil de la classe dominante → dépassement dans le communisme
  • Justice sociale : mérite, besoin, égalité (Rawls : voile d'ignorance)

La justice ▼

Définition : Principe d'attribution à chacun de ce qui lui revient, selon le droit, le mérite ou l'égalité.

  • Justice commutative : échanges équitables entre individus
  • Justice distributive : répartition équitable des biens dans la société
  • Justice et droit : le droit est-il toujours juste ? Droit naturel vs droit positif
  • Rawls : principe de différence — les inégalités ne sont acceptables que si elles bénéficient aux plus défavorisés
  • Vengeance vs punition : la peine doit-elle être rétributive ou réhabilitative ?
Platon : la justice = chacun à sa place, harmonie de l'âme et de la cité (République)

La morale ▼

Définition : Ensemble de règles guidant l'action pour distinguer le bien du mal.

  • Éthique des vertus (Aristote) : viser le bonheur (eudaimonie) par l'exercice des vertus
  • Déontologie (Kant) : agir selon le devoir — impératif catégorique
  • Conséquentialisme (utilitarisme, Mill) : l'action bonne maximise le bonheur du plus grand nombre
  • Relativisme moral : les valeurs morales sont-elles universelles ou culturelles ?
  • Morale et religion : peut-il y avoir une morale sans Dieu ?

Le bonheur ▼

Définition : État de satisfaction complète et durable. Distinct du plaisir (passager) et de la joie (intense mais momentanée).

  • Épicurisme : bonheur = ataraxie (absence de troubles) + aponie (absence de douleur)
  • Stoïcisme (Épictète) : bonheur = conformité à la raison, maîtrise de soi face à ce qui ne dépend pas de nous
  • Aristote : eudaimonie — vie selon la vertu et l'accomplissement de sa nature

Auteurs majeurs du programme — thèses essentielles à connaître.

Platon (428–348 av. J.-C.) ▼
  • Théorie des Idées : le monde sensible est une imitation du monde intelligible (les Idées, éternelles et parfaites)
  • Allégorie de la caverne (République) : l'éducation comme sortie de la caverne vers la lumière du Bien
  • L'âme tripartite : raison / thumos (cœur) / appétits — justice = harmonie des trois parties
  • L'art = imitation de l'imitation : dangereux car éloigne du vrai
  • Notions : vérité, art, justice, désir, connaissance
Textes clés : La République, Le Banquet, Phédon, Ménon
Aristote (384–322 av. J.-C.) ▼
  • Éthique des vertus : le bonheur (eudaimonie) comme finalité de l'homme — vertu = juste milieu
  • Politique : « L'homme est un animal politique » — la cité est naturelle
  • Logique : syllogisme, catégories, principe de non-contradiction
  • Causes : matérielle, formelle, efficiente, finale
  • Notions : bonheur, morale, justice, langage, nature
Textes clés : Éthique à Nicomaque, La Politique, Métaphysique
Descartes (1596–1650) ▼
  • Doute méthodique : douter de tout pour trouver une certitude indubitable
  • Cogito : « Je pense donc je suis » — première vérité indubitabe
  • Dualisme : distinction âme (res cogitans) et corps (res extensa)
  • Libre arbitre : infini et volonté distincte de l'entendement
  • Notions : conscience, liberté, vérité, raison
Textes clés : Méditations métaphysiques, Discours de la méthode, Traité des passions
Kant (1724–1804) ▼
  • Révolution copernicienne : ce n'est pas l'esprit qui s'adapte au monde, mais l'inverse — les catégories a priori structurent l'expérience
  • Impératif catégorique : agis comme si ta maxime devait devenir loi universelle
  • Critique de la métaphysique : raison pure (limites), raison pratique (morale), faculté de juger (esthétique)
  • Dignité humaine : l'homme est une fin en soi, jamais un simple moyen
  • Notions : liberté, morale, vérité, art, religion
Textes clés : Critique de la raison pure, Fondements de la métaphysique des mœurs, Critique de la faculté de juger
Spinoza (1632–1677) ▼
  • Monisme : une seule substance — Dieu = Nature (Deus sive Natura)
  • Déterminisme universel : tout est déterminé, le libre arbitre est une illusion
  • Conatus : chaque être tend à persévérer dans son être — le désir est l'essence de l'homme
  • La joie comme accroissement de puissance d'agir
  • Notions : liberté, désir, nature, religion
Textes clés : Éthique (more geometrico), Traité théologico-politique
Nietzsche (1844–1900) ▼
  • Mort de Dieu : effondrement des valeurs absolues — nihilisme comme diagnostic
  • Volonté de puissance : force créatrice, non violence — auto-dépassement
  • Éternel retour : aimer sa vie au point de vouloir la revivre infiniment
  • Généalogie de la morale : critiquer l'origine des valeurs (morale des esclaves vs des maîtres)
  • Notions : vérité, morale, bonheur, art, religion
Textes clés : Ainsi parlait Zarathoustra, Par-delà le bien et le mal, Généalogie de la morale
Freud (1856–1939) ▼
  • Topiques : 1ère (conscient/préconscient/inconscient) et 2ème (Ça/Moi/Surmoi)
  • Méthode : psychanalyse — associations libres, analyse des rêves, transfert
  • Mécanismes de défense : refoulement (principal), déni, projection, sublimation
  • Pulsions : Éros (vie) vs Thanatos (mort/destruction)
  • Notions : inconscient, conscience, désir, bonheur, religion
Textes clés : L'interprétation des rêves, Malaise dans la civilisation, Le Moi et le Ça
Sartre (1905–1980) ▼
  • Existentialisme : « L'existence précède l'essence » — on se définit par ses actes
  • Liberté absolue et responsabilité totale : mauvaise foi = se mentir sur sa liberté
  • Autrui : « L'enfer, c'est les autres » — le regard d'autrui m'objectifie
  • Engagement : l'intellectuel doit prendre parti (littérature engagée)
  • Notions : liberté, conscience, inconscient (critique Freud), existence
Textes clés : L'Être et le Néant, L'existentialisme est un humanisme, Huis Clos

📝 La dissertation philosophique — structure

  1. Introduction : accroche → définir les termes du sujet → problématiser → annoncer le plan
  2. Développement (3 parties) : thèse → antithèse → synthèse (ou dépassement)
  3. Conclusion : bilan du parcours → réponse à la question → ouverture
Comment problématiser un sujet ▼
  • 1. Définir les termes : plusieurs sens possibles, tensions entre eux
  • 2. Repérer les présupposés : ce que le sujet suppose implicitement
  • 3. Identifier la contradiction : deux réponses raisonnables en apparence opposées
  • 4. Formuler la problématique : une question qui montre pourquoi le sujet n'est pas évident

Exemple : « Peut-on se mentir à soi-même ? » → peut-on à la fois savoir quelque chose et ne pas le savoir ? (tension entre savoir et ignorer)

Comment construire un plan dialectique ▼
Thèse → Antithèse → Synthèse (dépassement)
  • Thèse : répondre « oui » à la question (ou défendre la position la plus attendue)
  • Antithèse : montrer les limites de la thèse, défendre la position inverse
  • Synthèse : dépasser l'opposition, nuancer, proposer une réponse plus fine
  • Chaque partie : idée directrice → argument → exemple → analyse de l'exemple
L'explication de texte — méthode ▼

Structure de l'explication

  1. Introduction : situer l'auteur et l'œuvre, annoncer la thèse du texte, dégager le problème
  2. Explication linéaire : suivre le texte pas à pas, expliquer chaque argument, concept clé, exemple
  3. Discussion : portée du texte, limites, mise en perspective avec d'autres auteurs
  4. Conclusion : synthèse de la thèse et de sa justification
  • Ne pas paraphraser : expliquer, c'est reformuler et justifier
  • Identifier les connecteurs logiques : « donc », « or », « cependant », « en effet »
  • Relier chaque idée à la thèse centrale du texte
  • Citer précisément les termes du texte entre guillemets
Mobiliser un auteur dans une copie ▼
  • Nommer l'auteur et situer brièvement (« Pour Kant, dans la Critique… »)
  • Exposer la thèse de l'auteur en rapport avec votre argument
  • Analyser : montrer en quoi ça appuie votre démonstration
  • Ne pas se contenter d'une citation isolée — l'analyser et l'intégrer
  • Varier les auteurs : ne pas rester sur un seul tout au long de la copie
Erreurs classiques à éviter ▼
  • ❌ Paraphrase : répéter le sujet sans analyser
  • ❌ Hors-sujet : traiter une notion sans la relier au sujet posé
  • ❌ Exemple non analysé : l'exemple illustre mais ne démontre pas seul
  • ❌ Absence de problématique : un plan sans tension n'est pas philosophique
  • ❌ Conclusion bâclée : elle doit répondre à la question posée
  • ✅ Toujours expliquer pourquoi, pas seulement quoi
